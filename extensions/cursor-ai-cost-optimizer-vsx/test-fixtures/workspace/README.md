# CCO fixture workspace

Small fixture repo used by the Cursor AI Cost Optimizer extension's integration tests and the
real-IDE proofs (`scripts/proof-ide-auth.sh`). The extension installs `.cursor/` assets and hooks here;
`utils/` is created by the IDE routing proof and cleaned before each run.

- `src/hello.js` - sample module
- `tokens.md` - scratch file used by the insert-token test
